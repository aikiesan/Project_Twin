# 22 — Glossary (PT / EN)

| Term | Meaning |
|---|---|
| **ACO** | Agente Certificador de Origem — certifies biomethane producers for CGOB (ANP Res. 996/2026) |
| **ADM1** | IWA Anaerobic Digestion Model No. 1 |
| **AHP** | Analytic Hierarchy Process (MCDA weighting) |
| **ANP** | Agência Nacional do Petróleo, Gás Natural e Biocombustíveis |
| **ARSESP** | Agência Reguladora de Serviços Públicos do Estado de SP (gas distribution regulator) |
| **ATR** | Açúcar Total Recuperável — total recoverable sugar |
| **Bagaço / bagasse** | Fibrous residue after crushing; burned in boilers |
| **Bio-Citygate** | Custody-transfer station for biomethane injection (ARSESP 1.765/2025) |
| **BMP** | Biochemical Methane Potential (NL CH₄/kg VS) |
| **B₀** | Maximum methane producing capacity of manure (IPCC) |
| **CAPEX / OPEX** | Investment / operating costs |
| **CBIO** | Crédito de Descarbonização (RenovaBio), traded on B3 |
| **CGOB** | Certificado de Garantia de Origem do Biometano; 1 CGOB = 100 m³ |
| **CNPE** | Conselho Nacional de Política Energética |
| **CNPJ** | Brazilian company/establishment tax ID (14 digits) — facility key |
| **COD / DQO** | Chemical oxygen demand |
| **CSTR** | Continuous stirred-tank reactor |
| **CUSD-Verde / TUSD-Verde** | Green distribution-use contract / tariff for biomethane interconnection (SP) |
| **DVC** | Data Version Control |
| **EDR** | Escritório de Desenvolvimento Rural (SP regional unit) |
| **Entressafra / off-season** | Period without cane crushing (~Dec–Mar in SP) |
| **FDE** | Feedstock-Dependent Efficiency factors (PILAR-2b availability method) |
| **Fertirrigação** | Application of vinasse to cane fields as fertilizer/irrigation |
| **FOS/TAC** | VFA / total alkalinity ratio (stability indicator) |
| **H3** | Uber hexagonal hierarchical spatial index |
| **HRT / TDH** | Hydraulic retention time |
| **Huff model** | Probabilistic spatial interaction (gravity) allocation model |
| **LAI** | Lei de Acesso à Informação (Lei 12.527/2011) |
| **LBG / LNG** | Liquefied biogas / natural gas |
| **LCOB** | Levelized cost of biomethane |
| **LUPA** | Levantamento Censitário das Unidades de Produção Agropecuária (SP farm census) |
| **MILP** | Mixed-integer linear programming |
| **NEEA** | Nota de Eficiência Energético-Ambiental (RenovaBio, gCO₂e/MJ) |
| **OLR / COV** | Organic loading rate (kg VS or COD/m³·d) |
| **P4.231** | CETESB technical norm for vinasse application to soil |
| **PAV** | Plano de Aplicação de Vinhaça (annual, per mill, to CETESB) |
| **Palha / straw** | Cane leaves and tops left after mechanical harvest |
| **RenovaBio / RenovaCalc** | National biofuels policy / its carbon-intensity calculator |
| **Safra / harvest season** | Crushing season (~Apr–Nov in SP) |
| **SAPCANA** | MAPA sugarcane production monitoring system |
| **SIMP** | ANP monthly product movement reporting system |
| **Sobol indices** | Variance-based global sensitivity measures |
| **Torta de filtro / filter cake** | Solid residue from cane juice filtration (~30–40 kg/t cane) |
| **UASB** | Upflow anaerobic sludge blanket reactor |
| **Vinhaça / vinasse (stillage)** | Liquid residue of ethanol distillation (~10–15 L/L ethanol) |
| **VS / TS** | Volatile solids / total solids |
| **VTN** | Valor da Terra Nua — bare-land price |
