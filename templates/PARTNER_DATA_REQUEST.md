# Partner data request — template (São Martinho / Comgás / Equinor)

**Purpose:** validation and calibration of the CP2B SP biomethane model. Data used under NDA; only aggregated/anonymized results published; partner reviews outputs before publication.

## Sugar-energy mill (e.g. São Martinho)
- [ ] Monthly crush (t), ethanol (anhydrous/hydrated, L), sugar (t) per unit, last 5–10 safras
- [ ] Vinasse generated vs applied (m³/month), concentration practices, composition (COD, SO₄, K) if measured
- [ ] Filter cake (t/month), current destination; straw recovered (t/yr)
- [ ] Harvest calendar per unit (start/end, stoppages)
- [ ] Biogas/biomethane project data (if any): capacity, CAPEX breakdown, OPEX, monthly output, downtime causes
- [ ] Digestate/fertirrigation logistics and cost

## Gas distributor (e.g. Comgás)
- [ ] Network layers (pressure classes, city gates, candidate injection points) — confirm vs what CP2B holds
- [ ] Connection cost references (R$/km by pressure/diameter; Bio-Citygate cost)
- [ ] TUSD-Verde values / methodology; quality & odorization requirements
- [ ] Demand by segment/region (aggregated); biomethane offtake conditions (non-price)

## Energy company / investor (e.g. Equinor)
- [ ] Investment criteria: hurdle IRR, WACC assumptions, contract structures
- [ ] Cost benchmarks from international portfolio (anonymized)
- [ ] Carbon-intensity / certification requirements for offtake

## Logistics
- Format: CSV/XLSX; contact: <name, e-mail>; storage: private DVC remote; retention: <period>.
